# Merged NSIS Website

This merged website keeps the two uploaded pages as one unified site:

- `index.html` — Knowledge & Policy Hub with calculator
- `lifecycle-chart.html` — D3 lifecycle policy chart

Shared features added:

1. Two main menu items: **Knowledge Hub** and **Lifecycle Chart**.
2. Dropdown submenus linking to specific sections inside each page.
3. Shared theme switcher with Emerald, Ocean, Midnight, and Classic themes.
4. Shared `site-theme.css` and `site-menu.js` for navigation, dropdowns, mobile menu, and theme persistence.

Open `index.html` in a browser to start. For the D3 chart, keep the `data/` folder in the same location as `lifecycle-chart.html`.
